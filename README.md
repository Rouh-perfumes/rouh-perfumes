## 🚀 طريقة رفع الموقع مجاناً على GitHub Pages (في 3 دقائق)

### الخطوة 1: إنشاء مستودع جديد على GitHub
1. ادخل على حسابك في [GitHub](https://github.com/) وسجل الدخول.
2. اضغط على الزر الأخضر **"New"** (لإنشاء New Repository).
3. سمّ المستودع باسم المتجر، مثلاً: `rouh-perfumes` أو `rouh-catalog`.
4. اجعل المستودع **Public** ثم اضغط **"Create repository"**.

### الخطوة 2: رفع الملفات
1. داخل صفحة المستودع الجديد، اضغط على **"uploading an existing file"** (أو Add file -> Upload files).
2. اسحب وأفلت الملفات التالية من مجلد المشروع:
   - `index.html`
   - `style.css`
   - `products.js`
   - `app.js`
3. اضغط على الزر الأخضر بالأسفل **"Commit changes"**.

### الخطوة 3: تفعيل الرابط المباشر (GitHub Pages)
1. من أعلى صفحة المستودع، اضغط على **Settings**.
2. من القائمة الجانبية على اليسار، اضغط على **Pages**.
3. تحت قسم **Build and deployment**:
   - عند **Source** اختر: `Deploy from a branch`.
   - عند **Branch** اختر: `main` (أو `master`) والمجلد `/ (root)`.
   - اضغط **Save**.
4. انتظر دقيقة واحدة، وستظهر لك رسالة خضراء برابط موقعك الحي، مثل:
   `https://<username>.github.io/rouh-perfumes/`
